# Model Weights

This project uses three YOLO models:

1. YOLO11m - Vehicle detection
2. YOLO11n-Pose - Human pose estimation
3. Custom-trained YOLO11n - Helmet detection

The custom helmet detection weights are distributed
separately through GitHub Releases.

Download the helmet model and place it in this folder
using the filename:

helmet_detector.pt

Pretrained Ultralytics weights are loaded separately.
